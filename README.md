### 💼 Portfolio & Hands-on Projects

Here is a showcase of my featured projects, complete with interactive demos and live source code.

#### 🚀 [EduFlow AI - Personalized Learning Platform](https://github.com/niraj987/eduflow-ai)
* **Description:** An educational platform combining DSA visualization (DFS, BFS, Dijkstra, Topological Sorting on graph syllabus), interactive client-side machine learning predictors (Gradient Descent Linear Regression and Decision Tree classifiers), an offline/online hybrid vector database RAG pipeline, lecture text summarizers with flippable revision cards, interactive study quizzes, and dynamic voice search / audio narration using the **Gemini 1.5 Flash API** and Web Speech API.
* **Tech Stack:** Vanilla JS, CSS3 (Glassmorphism design), HTML5, Gemini AI SDK, Web Speech API, RAG Vector Search.
* **Live Demo:** 🔗 [Launch EduFlow AI Web App](https://niraj987.github.io/eduflow-ai/)

#### 🩺 [Student Social Media & Mental Health Analytics](https://github.com/niraj987/student-social-media-mental-health)
* **Description:** Interactive prediction and analytics platform mapping the impact of social media usage on student mental wellness. Details screen time, engagement patterns, and predicts risks (depression/anxiety scoring) using machine learning classification.
* **Tech Stack:** Python, Streamlit, Scikit-Learn, Pandas, NumPy, Seaborn, Matplotlib.
* **Live Docs:** 🔗 [View Project Documentation Pages](https://niraj987.github.io/student-social-media-mental-health/)

#### 💳 [Credit Risk Modeling Platform](https://github.com/niraj987/Credit-Risk-Modeling)
* **Description:** A detailed credit risk assessment and probability of default (PD) prediction engine. Formulates model scorecards, analyzes loan parameters, and visualizes client default distributions to aid credit risk analysts.
* **Tech Stack:** Python, Streamlit, Scikit-Learn, Pandas, Seaborn, Matplotlib.
* **Live Docs:** 🔗 [View Risk Modeling Pages](https://niraj987.github.io/Credit-Risk-Modeling/)

#### 📈 [Sentiment Analysis on Social Media Feed](https://github.com/niraj987/sentiment-analysis-social-media)
* **Description:** NLP classifier scoring user feeds and posts. Categorizes public sentiment into Positive, Negative, or Neutral classes using pre-processed text pipelines, showing metrics over timeline distributions.
* **Tech Stack:** Python, Streamlit, Natural Language Toolkit (NLTK), Scikit-Learn, Pandas, Matplotlib.
* **Live Docs:** 🔗 [View Sentiment Analysis Pages](https://niraj987.github.io/sentiment-analysis-social-media/)

#### 🛡️ [Credit Card Fraud Detection Engine](https://github.com/niraj987/Credit-card-fraud-Detection)
* **Description:** ML classification pipelines trained to detect fraudulent transactions in highly imbalanced datasets. Utilizes specialized metrics (Precision-Recall curves) and model threshold tuning to identify anomalies.
* **Tech Stack:** Python, Streamlit, Scikit-Learn, Pandas, NumPy, Matplotlib.
* **Live Docs:** 🔗 [View Fraud Detection Pages](https://niraj987.github.io/Credit-card-fraud-Detection/)
